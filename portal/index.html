Cómo construí este portfolio

Este sitio no es una plantilla. Diseñé una arquitectura pensada para ser extensible y reproducible.

📦
Proyectos originales Cada demo parte de un proyecto real del repositorio
✂️
Demos aisladas Extraigo la funcionalidad relevante y la preparo como demo independiente
🐳
Containerización Cada demo se ejecuta en su propio contenedor con todo lo que necesita
🌐
Deployment Todos los contenedores se despliegan bajo una única URL
🎯
Portfolio El sitio accede a las demos y las presenta en iframes

Generación asistida

Para cada proyecto, le proporcioné a herramientas de IA el repositorio original junto con una descripción clara de qué debía mostrar la demo. A partir de esa información preparé demos reducidas que se integran fácilmente a la arquitectura.

Extensible por diseño

Agregar un nuevo proyecto/demostración es reproducible. El sistema está preparado para escalar sin rehacer la arquitectura base.
